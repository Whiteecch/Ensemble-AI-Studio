# 场景卡模板

> **给填写者（大模型）的填写说明 —— 请保留本说明块，不要删除或改写**
>
> 1. 只依据提供的小说素材填写；素材里没有的填 `（素材未提及）` 或留空，**不要编造**。
> 2. **每个字段名必须原样保留**（连同 `【】` 与冒号），程序靠它逐字段解析；不要增删章节标题。
> 3. 列表类字段**一行一条**，以 `- ` 开头；确实没有内容的写 `- （无）`。
> 4. 【出场角色】只能填写**角色卡里已有的姓名**（用户会另行提供角色名单）；不要写进没有角色卡的临时人物。
> 5. 若素材中**没有**明确的时间边界，【边界类型】填 `无`。
> 6. **不要输出 JSON**，不要加代码块。
> 7. 本模板描述**一个场景**（一个地点 + 一段连续时间）；素材跨越多场景时，请复制本模板逐一填写。

【开始时间】：（24 小时制 `HH:MM`，例 `21:30`；素材未写明就按情境给一个合理值）

【边界类型】：（`时间` / `物理` / `社会` / `目标` / `无` 五选一）

【边界值】：（仅当类型为「时间」时填 `HH:MM`，例 `22:00`；其它类型可填如 `雨停` `谈判破裂`；类型为「无」时留空）

【边界描述】：（一句话说明这个边界的含义，例：餐厅打烊 / 车来了 / 谈判破裂。会用于到点收束的提示语）

## 二、场景内容

【背景信息】：（世界观与设定：这个世界的规则、势力、前情。3~8 句，供所有角色共享的公共信息）

【场景描述】：（这个地点**现在**是什么样：陈设、光线、气味、在场的东西。2~5 句，具体可感）

【描述可改变】：（填 `是` 或 `否`。填「是」时，场景可以在剧情推进时改写上面的描述——例：`餐厅里有一些桌椅` → `餐厅里有一些破碎的桌椅，到处都是战斗后的痕迹`）

【剧情设定】：（你希望接下来往哪走。可以是走向、悬念或目标；场景会参考它在适当时机介入。1~3 句；没有就留空）

## 四、触发器 hooks（可选，没有就整节留空）

> 每条 hook = **条件** + **事件**。场景每一轮都会看一遍这些条件，条件成立就执行对应事件。
> **条件**用自然语言描述即可，例：`有人提起那封信` / `甲和丁已经开始互相指责` / `虚拟钟走到 21:50 之后`。
> **事件类型**三选一：
> - `上下文` —— 把一句话写进对话（内容写在【事件内容】）
> - `角色` —— 让某角色加入/离开/禁言。动作填 `加入` / `离开` / `禁言N回合`（N 为数字）/ `禁言` / `解禁`
> - `场景` —— 修改场景自身。改动填一行「键：值」，键取 `name` / `description` / `background` / `plot_direction` / `date`
> **显隐**：填 `显式` = 这件事会出现在对话里；填 `隐式` = 只在后台生效、读者看不到。
